# 🎨 디자인계열 학종·비실기 면접 AI 코치 (2027 업데이트)

> **홍익대학교(서울) 디자인학부 · 세종대학교 디자인이노베이션 · 한양대학교(ERICA) 디자인계열 맞춤형 면접 예상질문 및 STAR-L 모범답변 실시간 생성기**

본 웹 애플리케이션은 미술·디자인 계열 학생부종합전형(학종) 및 비실기 면접을 준비하는 수험생과 지도 교사, 학부모를 위한 올인원 서류 분석 및 구술 코칭 플랫폼입니다.

## 🌟 2027 신규 업데이트 핵심 기능

### 1. 🌸 옅은 핑크톤 감성 UI & 💙 코발트 블루 섹션 버튼
* **소프트 파스텔 핑크 테마**: 감각적이고 피로도 없는 옅은 핑크 톤(`--bg: #fff1f5;`) 배경과 깔끔한 로즈/블루 그라데이션 헤더 디자인
* **파란색 인터랙티브 섹션 버튼 (Vibrant Blue)**: 시각적 위계와 클릭성이 뛰어난 4대 주요 섹션 전환 버튼(`--btn-blue: #2563eb;`) 탑재

### 2. 📄 학생부·PDF A4 1장 입학사정관 서류평가표 & 예상질문 자동 추출
* **PDF / TXT 파일 자동 파싱**: 클라이언트 브라우저에서 `pdf.js`를 통해 학생부 PDF 파일의 텍스트를 즉시 자동 추출 (직접 텍스트 붙여넣기도 완벽 지원)
* **입학사정관 종합 서류평가 요약서**:
  * **지원자 기본 정보 & 종합 등급**: 평가위원 종합 의견 및 등급 산출 (A+ 상위 3.5% 등)
  * **4대 핵심 평가영역 진단 매트릭스**: 학업·기초조형소양 / 진로·창의융합(UX) / 공동체·협업인성 / 자기주도·발전가능성 정성평가
  * **핵심 프로젝트 3선 요약**: Why(문제발견) - How(조형/기술 해결) - Result(성과/배움) 구조화
  * **⚠️ 서류 진실성 위험요소 (Red Flag)**: 사정관 시선에서의 사교육 의혹, 도구 숙련도, 시행착오 디테일 등 집중 확인 요망 사항 도출
  * **🎯 서류 기반 입학사정관 심층 예상질문 4선**: 진위 검증 및 전공 스튜디오 연계 압박 질문 도출
* **🖨️ A4 용지 1장 인쇄 최적화 (`@media print`)**: 여백 없이 표준 A4 1장에 딱 맞게 출력되도록 전용 프린트 스타일 시트 적용

### 3. 📚 최근 5개년(2022~2026) 디자인계열 수시 면접 기출 실시간 아카이브
* **홍익대(서울) 디자인학부 (2022~2026 기출)**:
  * 2026: 전통 목가구 결구(도판 A) vs 현대 업사이클링 패키지(도판 B) 조형 분석 및 1인 가구 공공 수납 가구 제안
  * 2025: 바우하우스 모더니즘 기하학 vs 유기체 바이오모피즘 조형 분석 및 차세대 UI 위계 구술
  * 2024: 기후 위기 아카이빙 사진 도판을 활용한 공공 인터랙티브 인포그래픽 리디자인
* **세종대 창의소프트학부 디자인이노베이션 (2022~2026 기출)**:
  * 2026 오전: 제시문 '파동(Wave)' 원리를 해석하여 '접근성(Accessibility)'을 사물·인터페이스에 대입한 A3 구상지 시각화(드로잉·기호·글 3단 구성) 발표
  * 2026 오후: '가속도(Acceleration)'와 '유동성(Fluidity)'의 조화를 통한 미래 스마트 모빌리티 인터랙션
  * 2025: '권력 분립' 3요소를 '자율주행 안전 시스템(차량·도로·보행자)'에 대입 및 2점 투시 공간감 적용
* **한양대(ERICA) 디자인대학 (2022~2026 기출)**:
  * 산업/커뮤니케이션: 퍼스널 모빌리티 페인포인트 비판적 진단 및 제조 고려 설계(DFM) 양산성 검증
  * 영상/미디어: 생성형 AI 프롬프트 워크플로우와 디자이너의 고유 문제정의(Problem Finding) 역량 차별화
* **원클릭 기출 연동**: 기출 카드마다 `[⚡ 이 기출로 질문 & STAR-L 답변 생성하기]` 버튼을 통해 즉시 실전 모의면접으로 연결

## 🚀 빠른 시작 (Getting Started)

외부 서버 설치나 빌드 과정 없이 **웹 브라우저에서 `index.html`을 열면 모든 기능이 즉시 실행**되는 제로-디펜던시 순수 웹 앱입니다.

```bash
# 1. 저장소 클론
git clone https://github.com/kjh22432275/antigravity_lab.git
cd antigravity_lab

# 2. 로컬 프리뷰 서버 실행 (선택사항)
python3 -m http.server 8000
# 웹 브라우저에서 http://localhost:8000 접속
```

* **Frontend**: HTML5, Modern CSS3 (CSS Custom Properties, Responsive Grid/Flexbox, Print Stylesheet), Vanilla JavaScript (ES6+)
* **Libraries**: PDF.js (CDN-based Client-side PDF text extraction)
* **AI Integration**: Google Generative AI (Gemini 2.5-flash / 2.0-flash / 1.5-flash Multi-model Fallback)
* **Grounding DB**: 2022~2026 대학별 선행학습영향평가서 및 최신 디자인 산업 데이터 내장
