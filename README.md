# 🎨 디자인계열 학종·비실기 면접 AI 코치

> **홍익대학교(서울) 디자인학부 · 세종대학교 디자인이노베이션 · 한양대학교(ERICA) 디자인계열 맞춤형 면접 예상질문 및 STAR-L 모범답변 실시간 생성기**

본 프로젝트는 미술·디자인 계열 학생부종합전형(학종) 및 비실기 면접을 준비하는 수험생과 지도 교사, 학부모를 위한 올인원 웹 애플리케이션입니다. 학생부 세특 및 미술활동보고서 원문을 분석하여 대학별 평가 기준에 최적화된 4대 면접 질문과 STAR-L 구조의 1분 모범 답변, 압박 꼬리질문 방어 논리를 실시간으로 제공합니다.

---

## 🌟 주요 핵심 기능

### 1. 목표 대학별 특화 평가 엔진 탑재
* **홍익대학교(서울) 디자인학부 (미술우수자전형 - 면접 60%)**
  * 도판·제시문 조형 언어(비례, 대비, 위계, 어포던스 등) 분석 및 창의적 재해석 구술 대비
  * 미술활동보고서(교과·비교과) 및 세특 기재 활동의 진위·주도성·디자인 프로세스 심층 검증
* **세종대학교 창의소프트학부 디자인이노베이션전공 (세종창의인재(면접형) - 면접 30%)**
  * 실제 기출 유형(‘파동×접근성’, ‘가속도×유동성’) 기반 제시문 개념 융합 문항 출제
  * 구상지 시각화(도형·그림·기호·글 3분할 레이아웃) 작성 및 융합 구술 발표 전략 설계
* **한양대학교(ERICA) 디자인계열 (학생부종합 서류형 & 심층 면접 연계)**
  * 디자인대학 4개 전공(산업·커뮤니케이션·영상·주얼리패션) 맞춤 스토리텔링
  * IC-PBL(산업·사회 문제해결) 교육 철학에 맞춘 4대 역량(비판적·창의적·자기주도·소통협업) 정성평가 및 구술화
* **3개 대학 통합 올라운드 마스터 모드 & 전국 대학 커스텀 검색**
  * 대학명을 입력하면 즉시 해당 대학 디자인 학종 맞춤형 프레임워크 자동 생성

### 2. 세특 & 미술활동보고서 실시간 3대 역량 모니터링
* 텍스트를 입력하는 즉시 실시간으로 키워드를 파싱하여 다음 3대 역량을 시각적 게이지로 진단:
  * 🎨 **미술소양·조형분석력**
  * 💡 **창의융합·문제해결(UX)**
  * 🤝 **사용자공감·협업윤리**
* 시각·유니버설 UX, 산업·친환경소재, SW·물리 융합(세종대형), 영상·산학 PBL(한양대형)의 **4대 원클릭 프리셋 예시** 제공

### 3. STAR-L 프레임워크 기반 1분 모범 답변 생성
* **두괄식 결론 (Conclusion)**: 질문의 의도를 관통하는 1문장 핵심 답변
* **상황/과제 (Situation & Task)**: 문제 발견의 호기심 및 조형·융합적 목표 정의
* **행동 (Action)**: 시행착오 극복 과정, 시각적 위계/사용성 개선, 주도적 제작 원리
* **결과/배움 (Result & Learning)**: 전공 소양 확장 및 미래 디자이너로서의 철학 연결
* **디자인 교수진 압박 꼬리질문 2선**: 진위 확인, 조형 재설계, 상용화 한계, 융합 기술 결합 등 방어 논리 제공

### 4. 실전 리허설 & 훈련 도구
* ⏱️ **1분 구술 스피치 타이머**: 45초~60초 최적 구간 알림 및 '대본 가리고 키워드만 보고 말하기' 블라인드 훈련 기능
* ✅ **모의면접 11개 항목 자기점검표**: 구술 표현 태도 5문항 + 디자인 씽킹·서류 내용 검증 6문항
* 🤖 **초정밀 프롬프트 완성본**: ChatGPT / Gemini에 그대로 복사해 추가 질문을 뽑아볼 수 있는 프롬프트 엔지니어링 탭
* 💾 **면접장 지참용 인쇄/PDF 저장 및 텍스트(.txt) 다운로드** 기능 지원

### 5. Google Gemini API 실시간 연동 (선택사항)
* Google Gemini API Key 입력 시 최신 AI 모델을 통한 실시간 초개인화 답변 생성 가능
* API Key가 없어도 **내장된 오프라인 디자인 입학사정관 알고리즘**을 통해 100% 정상 작동

## 🚀 빠른 시작 (Getting Started)

본 프로젝트는 외부 서버나 빌드 도구 설치가 필요 없는 **순수 웹 애플리케이션(Single Page Application)**입니다.

### 실행 방법
1. 저장소를 클론합니다:
   ```bash
   git clone https://github.com/kjh22432275/antigravity_lab.git
   cd antigravity_lab
   ```
2. 웹 브라우저(Chrome, Safari, Edge 등)에서 `index.html` 파일을 더블 클릭하여 바로 실행합니다.
   * 또는 로컬 개발 서버를 이용할 경우:
     ```bash
     python3 -m http.server 8000
     # 브라우저에서 http://localhost:8000 접속
     ```

### GitHub Pages 무료 배포
* 본 저장소의 **Settings -> Pages**에서 `Branch: main`, `Folder: / (root)`를 지정하면 누구나 접속 가능한 웹 서비스로 즉시 배포할 수 있습니다.
